# Hi, I'm Gabriel

I'm a developer. I don't want to just prompt AI to build features and call it a day. I build things, try to understand how they work, and figure out how to make them work better.

I work in industrial automation, building applications that connect the real world with the digital one.

When I'm not working, I'm probably learning something new, drawing, or playing a videogame.

### What I'm into

- **Web development** — React, Node.js, Express, MongoDB.
- **Industrial automation** — PLCs, Node-RED, data acquisition and monitoring.
- **Building things** — from practical tools and integrations to personal software projects.
- **Videogames & technology** — both as a player and as someone curious about how things work under the hood.
